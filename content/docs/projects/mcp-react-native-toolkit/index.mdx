## Overview

`mcp-react-native-toolkit` is a local Model Context Protocol server that gives coding agents reliable React Native and Expo context plus utility tooling.

- Repository: [github.com/ItamiForge/mcp-react-native-toolkit](https://github.com/ItamiForge/mcp-react-native-toolkit)

## What it provides

- React Native and Expo-focused reference context
- Local device and simulator workflow helpers
- Secure local command execution patterns for agent-assisted development

## Position in the portfolio

This project represents infrastructure work: less UI-heavy, but high leverage for day-to-day mobile engineering throughput.
