## Command model

`pf` supports both immediate command usage and an interactive TUI workflow for rapid diagnosis.

## Platform notes

- Built with Rust.
- Uses `netstat2`, `sysinfo`, and `ratatui`.
- Targeted for macOS, Linux, and Windows.

## Next milestones

1. Add richer filtering and sort controls in TUI.
2. Add safer kill flow with stronger process context.
3. Add exportable diagnostics output for debugging sessions.
