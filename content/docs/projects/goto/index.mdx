## Overview

`goto` is a single binary for jumping between common roots and projects using namespace-based paths.

## Install

```bash
cargo install --path tools/goto
```

Or from the project root:

```bash
cargo install --path .
```

Run `goto setup` after install to wire the zsh helper into `~/.zshrc`. Restart your shell to pick up the `goto` function and tab completion. To remove it later, run `goto uninstall` before `cargo uninstall goto`.

**Note**: Without running `goto setup`, the `goto` command will only print resolved paths to stdout without changing directories or providing tab completion.

## Typical usage

```bash
goto gh
goto gh/project
goto gh/project/src
```

## Why it exists

It removes repetitive `cd` patterns and lowers friction when moving between many repositories.
