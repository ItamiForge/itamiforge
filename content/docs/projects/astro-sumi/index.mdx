## Overview

`astro-sumi` is a production-ready Astro template focused on writing-heavy sites, static exports, and clean publishing workflows.

- Repository: [github.com/ItamiForge/astro-sumi](https://github.com/ItamiForge/astro-sumi)
- Live demo: [itamiforge.github.io/astro-sumi](https://itamiforge.github.io/astro-sumi/)

## Why it matters

- Establishes a reusable baseline for content-first sites.
- Optimized for GitHub Pages and static deployment.
- Built as a template repo to accelerate spin-up for new content products.

## Scope

- Astro project structure and theme baseline
- Blog and writing-oriented UX patterns
- Static build and deployment pipeline
