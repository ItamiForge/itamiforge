## Overview

`shadcn-theme-builder` is an internal playground for theme primitives, component previews, and rapid style iteration.

## Current state

- Based on a Next.js app structure.
- Includes reusable UI components and dashboard-style examples.
- Used as a visual prototyping surface rather than a published product.

## Practical usage

Use this workspace to quickly test token combinations before pushing visual decisions into production apps.
