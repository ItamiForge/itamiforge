## Problem

Brewery SOPs often live in static documents and tribal knowledge, causing drift and inconsistent execution.

## Product concept

BrewRun is a live SOP runner that prompts operators through step execution while capturing structured logs.

## Core ideas

- Code-as-config workflows defined in human-editable YAML.
- Active execution flow with prompts and checks.
- Immutable run history for audit and diagnostics.

## Value

Consulting teams can standardize operations remotely and verify process adherence with data.
