## TUI controls

- Arrow keys or `j/k` to navigate.
- `Space` to toggle items.
- `Tab` to switch dashboard/list.
- `c` to clean selected paths.
- `r` to rescan.

## Safety posture

Kirei is built for cautious operation: scan first, selective action second, and recoverability via Trash.

## Next milestones

1. Add CLI-safe cleanup options with explicit confirmation.
2. Add richer scan filters by category and size threshold.
3. Publish release binaries and install docs.
