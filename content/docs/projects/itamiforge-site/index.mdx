## Overview

This repository powers the public ItamiForge studio site and docs hub.

- Repository: [github.com/ItamiForge/itamiforge](https://github.com/ItamiForge/itamiforge)
- Live site: [itamiforge.github.io/itamiforge](https://itamiforge.github.io/itamiforge/)

## Stack highlights

- Next.js App Router with static export
- Fumadocs for docs and blog content
- TypeScript strict mode and Biome
- GitHub Pages deployment pipeline

## Purpose

Acts as the canonical portfolio surface for public projects and curated documentation.
