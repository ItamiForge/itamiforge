## CLI Reference

Device Finder (`df`) provides a comprehensive command-line interface for device discovery and management.

### Entry point

```bash
df [COMMAND] [OPTIONS]
```

Run without a command to launch interactive TUI mode:

```bash
df                  # Interactive device browser
```

## Commands

### list

Display all detected devices in a formatted table.

```bash
df list [OPTIONS]
```

**Options:**

| Option | Description |
|--------|-------------|
| `--platform <ios\|android\|web>` | Filter by platform |
| `--verbose` | Show detailed device information |
| `--json` | Output as JSON array |

**Examples:**

```bash
# List all devices
df list

# List only iOS simulators
df list --platform ios

# List Android with verbose details
df list --platform android --verbose

# JSON output for scripting
df list --json
```

### find

Search devices by name, ID, or model.

```bash
df find <QUERY> [OPTIONS]
```

**Options:**

| Option | Description |
|--------|-------------|
| `--json` | Output as JSON object |

**Examples:**

```bash
# Find all iPhones
df find "iPhone"

# Find specific emulator
df find "emulator-5554"

# JSON output
df find "Pixel" --json
```

**Exit codes:**

- `0`: Device(s) found
- `3`: No matching device

**JSON output shape:**

```json
{
  "query": "iPhone",
  "found": true,
  "devices": [ { ...device objects... } ]
}
```

```bash

```

**Options:**

| Option | Description |
|--------|-------------|
| `--json` | Output as JSON object |

**Examples:**

```bash

# JSON output
df info "7754174C-C8D6-4248-BB30-A6EE9539C63E" --json
```

**Terminal output:**

### launch

Boot or launch a device.

```bash
df launch <DEVICE_ID> [OPTIONS]
```

**Options:**

| Option | Description |
|--------|-------------|
| `--json` | Output as JSON object |

**Examples:**

```bash
# Launch iOS simulator
df launch "ABC123DEF456"

# Launch Android emulator
df launch "emulator-5554"

# JSON output for automation
df launch "device-id" --json
```

**Exit codes:**

- `0`: Launch initiated
- `1`: Launch failed

**JSON output shape:**

```json
{
  "action": "launch",
  "device_id": "device-id",
  "status": "initiated",
  "message": "Device launch initiated"
}
```

### install

Install an app or bundle on a device.

```bash
df install <DEVICE_ID> <BUNDLE_PATH> [OPTIONS]
```

**Options:**

| Option | Description |
|--------|-------------|
| `--json` | Output as JSON object |

**Examples:**

```bash
# Install app on device
df install "device-id" "/path/to/app.ipa"

# Install on Android
df install "emulator-5554" "/path/to/app.apk"

# JSON output
df install "device-id" "/path/to/app" --json
```

**Exit codes:**

- `0`: Installation initiated
- `1`: Installation failed

**JSON output shape:**

```json
{
  "action": "install",
  "device_id": "device-id",
  "bundle": "/path/to/bundle",
  "status": "initiated",
  "message": "App installation initiated"
}
```

### connect

Establish connection to a device.

```bash
df connect <DEVICE_ID> [OPTIONS]
```

**Options:**

| Option | Description |
|--------|-------------|
| `--json` | Output as JSON object |

**Examples:**

```bash
# Connect to wireless device
df connect "192.168.1.100:5555"

# Connect to USB device
df connect "device-serial"

# JSON output
df connect "device-id" --json
```

**Exit codes:**

- `0`: Connection initiated
- `1`: Connection failed

## Exit Codes

Device Finder uses standardized exit codes for automation:

| Code | Meaning |
|------|---------|
| `0` | Success (device found, action executed, etc.) |
| `1` | Error (invalid input, tool not available, etc.) |
| `3` | Not found (for `find` and `info` commands) |

## JSON Output

All commands support `--json` for machine-readable output:

```bash
# List devices as JSON
df list --json

# Find with JSON
df find "query" --json

# Get device details as JSON
df info "device-id" --json

# Action commands return JSON status
df launch "device-id" --json
```

JSON output can be piped to tools like `jq`:

```bash
# Get device IDs
df list --json | jq -r '.[].id'

# Get connected devices only
df list --json | jq '.[] | select(.status == "Connected")'

# Count devices by platform
df list --json | jq 'group_by(.platform) | map({platform: .[0].platform, count: length})'
```

## Configuration

Device Finder reads optional config from `~/.config/itamiforge/device-finder/config.toml`:

```toml
[platforms]
# Filter devices by platform on startup
default_filter = ["ios", "android"]

# Exclude specific devices from listings
exclude_devices = ["old-simulator"]

[tools]
# Override tool paths if they're not in PATH
adb_path = "/usr/local/bin/adb"
xcrun_path = "/Applications/Xcode.app/Contents/Developer/usr/bin/xcrun"
emulator_path = "/Users/varunv/Library/Android/sdk/emulator/emulator"
```

Create the config directory:

```bash
mkdir -p ~/.config/itamiforge/device-finder
```

## Scripting Examples

### Get all device IDs

```bash
df list --json | jq -r '.[].id'
```

### Boot all shutdown iOS simulators

```bash
df list --platform ios --json | \
  jq -r '.[] | select(.status == "Shutdown") | .id' | \
  while read -r id; do xcrun simctl boot "$id"; done
```

### Check if a specific device exists

```bash
df find "iPhone 17 Pro" --json | jq -e '.found'
# true → exit 0, false → exit 3
```

### Monitor device count changes

```bash
#!/bin/bash
prev=0
while true; do
  count=$(df list --json | jq 'length')
  [ "$count" -ne "$prev" ] && echo "$(date): $prev → $count devices" && prev=$count
  sleep 5
done
```
