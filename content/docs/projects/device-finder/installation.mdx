# Installation & Setup

Device Finder is distributed as a Rust crate and can be installed from source or via cargo.

## Prerequisites

### Required

- [Rust](https://rustup.rs/) (1.70+ recommended)
- Cargo (included with Rust)

### Platform-Specific

**macOS (for iOS support):**
- Xcode with Command Line Tools
- `xcrun` available in PATH

**Android (all platforms):**
- Android SDK with `adb` in PATH
- `emulator` command available (for emulator detection)

**All platforms:**
- Terminal with Unicode support (for emoji rendering)

## Install from Source

### Method 1: Clone and Install

```bash
# Clone the repository
git clone https://github.com/varun/itamiforge.git
cd itamiforge/tools/device-finder

# Build and install
cargo install --path .
```

### Method 2: Direct cargo install (if published)

```bash
cargo install device-finder
```

### Build Options

```bash
# Debug build (faster compile, slower runtime)
cargo build

# Release build (optimized)
cargo build --release

# Binary location after build
./target/release/device-finder
```

## Verify Installation

```bash
# Check version
device-finder --version

# Quick test
device-finder list
```

## Shell Completion

### Bash

```bash
device-finder completions bash > /etc/bash_completion.d/device-finder
```

### Zsh

```bash
device-finder completions zsh > "${fpath[1]}/_device-finder"
```

### Fish

```bash
device-finder completions fish > ~/.config/fish/completions/device-finder.fish
```

## Uninstall

```bash
cargo uninstall device-finder
```

## Troubleshooting

### "command not found: device-finder"

Cargo installs to `~/.cargo/bin` by default. Ensure it's in your PATH:

```bash
# Add to ~/.bashrc, ~/.zshrc, or equivalent
export PATH="$HOME/.cargo/bin:$PATH"
```

### iOS devices not detected

Verify Xcode Command Line Tools:

```bash
xcode-select --install
xcrun simctl list devices available
```

### Android devices not detected

Verify ADB is accessible:

```bash
adb devices -l
which emulator
```

### Unicode/emoji display issues

If emojis appear as boxes or question marks:

1. Use a terminal with Unicode support (iTerm2, Warp, Alacritty, Windows Terminal)
2. Install a Nerd Font or font with emoji support
3. Set your terminal's character encoding to UTF-8
