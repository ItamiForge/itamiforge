## Proposed stack

- Python backend for analytics and data processing.
- React + D3 front-end for interactive visualization.
- CSV/Excel ingest first, API integrations second.

## Critical metrics

- Brewhouse efficiency.
- Cellar efficiency.
- Packaging efficiency.
- Total system yield.

## Phase plan

1. Data ingestion and normalization.
2. Loss calculations with benchmark overlays.
3. Visual reporting and trend dashboards.
