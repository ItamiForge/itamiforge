## Overview

`kageasset` is a Rust CLI for scanning project image assets and generating concise metadata reports useful for content pipelines and QA checks.

- Repository: [github.com/ItamiForge/kageasset](https://github.com/ItamiForge/kageasset)

## Core use cases

- Inventorying asset folders quickly
- Identifying image dimensions and file characteristics
- Producing clean summaries for review and automation handoff

## Notes

The project is intentionally focused and lightweight, built to be composed into larger content or game asset workflows.
