# Vibe-Check

![Vibe-Check Header](/vibe-check/logo.png)

`vibe-check` is a comprehensive codebase hygiene tool designed to ensure architectural consistency and remove "AI Slop" from the project.

## 🚀 The Vision

In a world where 90% of code is generated by agents, the role of the developer shifts to **Vibe Orchestrator**. `vibe-check` provides the observability and linting required to keep a synthetic codebase feeling human, pragmatic, and architecturally sound.

## 🛠 Features

- **Slop Hunter**: Purge conversational AI residue and "Model Mouth" from comments and docs.
- **Vibe Indexing**: Use vector embeddings to ensure new code matches the "Architectural Vibe" of the project baseline.
- **GhostCode Integration**: Identify unreachable exports and bloat introduced by over-eager generators.
