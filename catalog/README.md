# Studio catalog

This hub lists ItamiForge projects from GitHub. Facts come from each repo's
`.itamiforge.yml` plus GitHub metadata. Literature stays optional and is not
generated by sync.

## Precedence

Membership is decided in this order. First match wins.

1. **Hub denylist** — never list, even if the repo opts in or is allowlisted.
2. **Unallowlisted fork** — skip forks unless the hub allowlist names them.
3. **Invalid `.itamiforge.yml`** — skip and report `invalid_contract`.
4. **Repo `catalog: false`** — the repo opted out. Allowlist cannot override this.
5. **Repo `catalog: true`** — include. YAML fields win over allowlist overlays and GitHub.
6. **Hub allowlist** — include when there is no contract file (bootstrap or extra-org).
7. **Default** — skip.

Field merge for an included project:

1. Repo YAML (explicit keys)
2. Hub allowlist overlay (explicit keys)
3. GitHub API (language, timestamps, homepage, archive flag, html_url)
4. Defaults (`featured: false`, `visibility: public`)

GitHub `archived: true` forces `status: archived`.
GitHub `private: true` forces `visibility: stub` and never copies file contents.

Private repos that are not included are omitted from `snapshot.json` so this
public site does not leak names.

## Commands

```bash
bun run sync:catalog
bun run sync:catalog -- --local-dir /Users/varunv/Documents/GitHub
```

CI runs `sync:catalog` on a schedule and opens a PR when `catalog/snapshot.json` changes.
Build uses the committed snapshot. It does not call GitHub.
