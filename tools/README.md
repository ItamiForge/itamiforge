# utils

Developer utilities and tools.

## Tools

### Navigation
- [x] **zsh-dev-nav** - `goto gh/project` with tab completion (Rust-powered)

### Ports & Processes
- [x] **port-finder** - Find and kill processes on a port (Rust CLI with TUI)

### Git & Version Control
- [ ] **git-who** - Who last touched each function/section in a file
- [ ] **git-standup** - What did I work on yesterday/this week
- [ ] **git-nuke** - Clean merged branches, prune remotes, gc
- [ ] **git-fixup** - Interactive rebase helper for quick fixups

### Project Health
- [ ] **proj-health** - Outdated deps, missing env vars, stale TODOs
- [ ] **proj-init** - Bootstrap configs (.gitignore, .editorconfig, etc)
- [ ] **dep-tree** - Visualize project dependency graph
- [x] **kirei** - macOS system cleaner (Xcode, Node, Cargo, Caches)

### Game Dev Specific
- [ ] **asset-watch** - Watch folder, auto-convert/optimize assets (png→webp, wav→ogg)
- [ ] **sprite-pack** - Pack sprites into atlases from CLI
- [ ] **tiled-export** - Convert Tiled maps to engine-specific formats
- [ ] **build-multi** - Build for multiple platforms in parallel
- [ ] **playtest-log** - Capture and filter game logs during playtesting

### Data & Analysis
- [ ] **csv-peek** - Quick stats and preview of CSV/parquet files
- [ ] **json-flatten** - Flatten nested JSON for analysis
- [ ] **sql-explain** - Format and explain query plans
- [ ] **log-filter** - Filter and colorize log files by level/pattern

### Productivity
- [ ] **note** - Quick CLI notes with timestamps, searchable
- [ ] **timer** - Pomodoro/task timer from terminal
- [ ] **env-switch** - Manage multiple .env profiles per project
- [ ] **wip** - Manage work-in-progress branches across repos

### Text & Code
- [ ] **diff-lines** - Show only changed line numbers
- [ ] **code-count** - LOC stats by language, excluding generated
- [ ] **snippet** - Save and retrieve code snippets from CLI
- [ ] **todo-scan** - Find all TODOs/FIXMEs with context

### Network & API
- [ ] **req** - Simpler curl with saved requests per project
- [ ] **mock-server** - Instant JSON API from a file
- [ ] **webhook-test** - Receive and inspect webhooks locally

### File Operations
- [ ] **bulk-rename** - Batch rename with patterns/regex
- [ ] **dupe-find** - Find duplicate files by content hash
- [ ] **size-tree** - Disk usage treemap in terminal
