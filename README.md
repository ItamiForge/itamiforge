# ItamiForge

Game and App studio blogging and docs site

## Local development

```bash
bun install
bun run dev
```

Open <http://localhost:3000>.

## Quality checks

```bash
bun run check
bun run build
```

## Deployment target

Project Pages deployment target:

- URL: <https://itamiforge.github.io/itamiforge/>
- Base path: `/itamiforge`
- Static output directory: `out/`
